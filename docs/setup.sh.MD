# docs /setup.sh

این فایل یک اسکریپت راه‌اندازی ربات روی Ubuntu و سیستم‌های مبتنی بر apt است.

## مراحل اسکریپت

1. **دانلود پروژه**
   - پروژه را دریافت می‌کند.

2. **نصب Python و نسخه خاص**
   - پایتون را با نسخه مشخص‌شده نصب می‌کند.

3. **ایجاد venv**
   - یک محیط مجازی (Virtual Environment) ایجاد می‌کند.

4. **نصب ابزارهای build پروژه و موارد لازم**
   - پیش‌نیازهای build و ابزارهای موردنیاز پروژه را نصب می‌کند.

5. **فعال‌سازی venv و نصب requirements**
   - محیط مجازی را فعال کرده و سپس وابستگی‌ها را از روی فایل requirements نصب می‌کند.

6. **ساخت فایل .env و دریافت مقادیر مورد نیاز از کاربر**
   - فایل `.env` را ایجاد می‌کند و مقادیر لازم را از طریق ورودی کاربر دریافت می‌کند.

7. **ساخت Service برای ربات و فعال‌سازی آن**
   - فایل سرویس (systemd) برای اجرای ربات می‌سازد و آن را فعال می‌کند.
