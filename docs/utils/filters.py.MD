# docs /utils/filters.py

این فایل برای فیلتر کردن دسترسی کاربران بر اساس عضویت در کانال‌های تبلیغاتی استفاده می‌شود.  
هدف اصلی آن این است که قبل از اجرای برخی دستورات یا callbackها، بررسی شود کاربر عضو کانال‌های لازم هست یا نه.

## توابع

### `is_member_of_channel(client, message)`
این تابع بررسی می‌کند که کاربرِ فرستنده‌ی پیام در تمام کانال‌های تبلیغاتی عضو هست یا نه.

**ورودی:**
- `client`: کلاینت Pyrogram
- `message`: پیام دریافتی از کاربر

**رفتار:**
- اگر `message.from_user` وجود نداشته باشد، `False` برمی‌گرداند.
- اگر هیچ کانال تبلیغاتی تعریف نشده باشد، `True` برمی‌گرداند و اجازه ادامه می‌دهد.
- برای هر کانال داخل `ADS_CHANNELS`، عضویت کاربر را چک می‌کند.
- اگر کاربر عضو نباشد یا خطایی مثل `UserNotParticipant` / `PeerIdInvalid` رخ دهد:
  - پیام «لطفا ابتدا در کانال‌های زیر عضو شوید» ارسال می‌شود
  - همراه با دکمه‌های کانال‌ها از طریق `build_ads_channels`
  - و `False` برمی‌گردد
- اگر همه بررسی‌ها موفق باشند، `True` برمی‌گرداند.

---

### `_join_filter_func(_, client, message)`
این تابع یک wrapper با ساختار مناسب برای `filters.create` است.

**کارکرد:**
- فقط `is_member_of_channel` را با سیگنچر درست برای فیلتر Pyrogram اجرا می‌کند.

**نکته:**
- این تابع مستقیماً در هندلرها استفاده نمی‌شود
- فقط برای ساخت فیلتر اختصاصی کاربرد دارد

---

### `is_member_of_channel_cb(client, callback)`
این تابع بررسی می‌کند که کاربرِ callback در کانال‌های تبلیغاتی عضو هست یا نه.

**ورودی:**
- `client`: کلاینت Pyrogram
- `callback`: callback query

**رفتار:**
- اگر کانالی در `ADS_CHANNELS` نباشد، `True` برمی‌گرداند.
- عضویت کاربر را برای همه کانال‌ها بررسی می‌کند.
- اگر کاربر عضو نباشد:
  - با `callback.answer(...)` یک هشدار نشان می‌دهد
  - و `False` برمی‌گرداند
- در صورت بروز خطای نامشخص، لاگ ثبت می‌شود و `False` برمی‌گردد

---

### `_join_filter_cb_func(_, client, callback)`
این تابع wrapper مخصوص `filters.create` برای callback query است.

**کارکرد:**
- `is_member_of_channel_cb` را با سیگنچر مناسب برای فیلتر Pyrogram اجرا می‌کند.

---

### `normalize_ads_chat_id(channel)`
این تابع شناسه‌ی کانال تبلیغاتی را نرمال‌سازی می‌کند.

**رفتار:**
- اگر مقدار کانال یک رشته‌ی عددی باشد، آن را به `int` تبدیل می‌کند
- در غیر این صورت همان مقدار را برمی‌گرداند

**کاربرد:**
- برای سازگار کردن `chat_id` قبل از استفاده در `get_chat_member`

## فیلترهای ساخته‌شده

### `join_filter`
فیلتر آماده برای استفاده در هندلرهای پیام است.

- بر اساس `_join_filter_func` ساخته می‌شود
- عضویت کاربر در کانال‌ها را قبل از اجرای هندلر چک می‌کند

---

### `join_filter_cb`
فیلتر آماده برای callback query است.

- بر اساس `_join_filter_cb_func` ساخته می‌شود
- قبل از اجرای callback handler عضویت کاربر را بررسی می‌کند

## جمع‌بندی

این فایل یک لایه‌ی کنترلی برای محدود کردن دسترسی کاربران ایجاد می‌کند تا فقط کاربرانی که در کانال‌های تبلیغاتی عضو هستند بتوانند از برخی بخش‌های ربات استفاده کنند.
