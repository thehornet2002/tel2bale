# docs /utils/keyboards.py

این فایل مسئول ساخت کیبوردهای اینلاین ربات است.  
تمام دکمه‌های اصلی، مدیریتی، بازگشت، و انتخاب‌های تأییدی از اینجا ساخته می‌شوند.

## توابع

### `build_start_keyboard(is_admin)`
این تابع کیبورد اولیه‌ی `/start` را می‌سازد.

**کارکرد:**
- دکمه‌های تنظیمات اصلی را نمایش می‌دهد
- در صورت فعال بودن لینک حمایت مالی، دکمه‌ی مربوط به آن را اضافه می‌کند
- دکمه‌ی راهنمای استفاده از ربات را اضافه می‌کند
- اگر `SUPPORT_MESSAGE` فعال باشد، دکمه‌ی ارسال پیام به پشتیبانی را هم نمایش می‌دهد
- لینک GitHub پروژه را اضافه می‌کند
- اگر کاربر ادمین باشد، دکمه‌ی **پنل مدیریت** هم اضافه می‌شود

**دکمه‌های اصلی این بخش:**
- تنظیم ID عددی بله
- تنظیم Bot Token بله
- تنظیم Access Key و Secret Key برای S3
- حمایت مالی
- راهنمای استفاده از ربات
- ارسال پیام به پشتیبانی
- GitHub
- پنل مدیریت (فقط برای admin)

---

### `build_back_keyboard()`
این تابع یک کیبورد ساده برای بازگشت می‌سازد.

**کارکرد:**
- فقط یک دکمه‌ی **بازگشت** دارد
- برای برگشت به `start_keyboard` استفاده می‌شود

---

### `build_back_management_keyboard()`
این تابع کیبورد بازگشت به بخش مدیریت را می‌سازد.

**کارکرد:**
- یک دکمه‌ی **بازگشت** نمایش می‌دهد
- کاربر را به منوی مدیریت برمی‌گرداند

---

### `build_management_keyboard()`
این تابع کیبورد اصلی پنل مدیریت را می‌سازد.

**کارکرد:**
- ابزارهای مدیریتی ربات را در اختیار admin قرار می‌دهد
- شامل عملیات مربوط به دیتابیس، بن/آنبن، محدودیت‌ها، تبلیغات، پشتیبانی و مدیریت ادمین‌ها است

**گزینه‌های این بخش:**
- دریافت فایل دیتابیس
- بن با ID بله
- آنبن با ID بله
- بن با ID تلگرام
- آنبن با ID تلگرام
- نمایش 10 کاربر پر مصرف
- تنظیم عکس پروفایل ربات
- مشاهده پیام‌های بخش پشتیبانی
- تغییر لینک دونیت
- تنظیم محدودیت برای همه
- تنظیم محدودیت برای یک نفر
- ایجاد Join اجباری
- حذف Join اجباری
- ارسال تبلیغات
- ارسال پیام به فرد خاص
- اضافه کردن ادمین
- حذف ادمین
- بازگشت

---

### `build_ads_channels(channels: list)`
این تابع کیبورد مربوط به کانال‌های تبلیغاتی را می‌سازد.

**کارکرد:**
- برای هر کانال یک دکمه جدا می‌سازد
- اگر کانال لینک قابل استفاده داشته باشد، دکمه به‌صورت URL ساخته می‌شود
- اگر کانال فقط یک شناسه عددی باشد، به‌جای لینک، متن کانال نمایش داده می‌شود
- در انتها دکمه‌ی **عضو شدم** را اضافه می‌کند

**رفتار بر اساس نوع ورودی:**
- `http://` یا `https://` → لینک مستقیم
- `@channel` → تبدیل به لینک تلگرام
- متن غیرعددی → تبدیل به لینک تلگرام
- شناسه عددی → نمایش به‌صورت متن

**کاربرد:**
- زمانی که کاربر باید در کانال‌های تبلیغاتی عضو شود

### `support_keyboard()`
این تابع کیبورد مربوط به پیام‌های پشتیبانی را می‌سازد.

**کارکرد:**
- دکمه‌ی دریافت پیام دیگر

**کاربرد:**

---

### `yes_or_no_bale_id()`
این تابع کیبورد تأیید/رد مربوط به `bale_id` را می‌سازد.

**کارکرد:**
- اگر کاربر قبلاً `bale_id` تنظیم کرده باشد، این کیبورد نمایش داده می‌شود
- دو گزینه دارد:
  - **بله** برای ریست کردن
  - **خیر** برای برگشت

---

**کارکرد:**

- دو گزینه دارد:
  - **بله** برای ریست کردن کلیدهای S3
  - **خیر** برای برگشت

---

**کارکرد:**
- زمانی که کاربر قبلاً Bot Token را ثبت کرده باشد، نمایش داده می‌شود

## جمع‌بندی

این فایل تمام کیبوردهای اینلاین ربات را مدیریت می‌کند و نقش مهمی در تجربه کاربری و بخش مدیریت دارد.  
از منوی شروع گرفته تا پنل ادمین و بخش عضویت در کانال‌ها، همه از همین فایل ساخته می‌شوند.
