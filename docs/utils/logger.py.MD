
# docs /utils/logger.py

این فایل برای مدیریت لاگ‌های پروژه استفاده می‌شود.  
هدف آن ثبت رویدادها، خطاها و پیام‌های مهم برنامه به‌صورت منظم در فایل و کنسول است.

## توابع

### `setup_logger()`
این تابع تنظیمات اولیه‌ی سیستم لاگ را انجام می‌دهد.

**کارکرد:**
- پوشه‌ی `logs` را در صورت نبودن ایجاد می‌کند
- فرمت نمایش لاگ‌ها را مشخص می‌کند
- لاگ‌ها را هم در فایل و هم در کنسول نمایش می‌دهد
- فایل لاگ را هر **15 دقیقه** یک‌بار می‌چرخاند (rotate)
- فقط **4 فایل قبلی** را نگه می‌دارد

**جزئیات:**
- لاگ‌های فایل در مسیر `logs/bot.log` ذخیره می‌شوند
- از `TimedRotatingFileHandler` برای چرخش زمانی لاگ استفاده شده است
- سطح لاگ فایل روی `DEBUG` تنظیم شده تا جزئیات کامل ثبت شوند
- سطح لاگ کنسول روی `INFO` تنظیم شده تا خروجی خواناتر باشد

**نکته:**
- این تابع باید فقط **یک‌بار** و معمولاً از `main.py` فراخوانی شود

---

### `get_logger(name)`
این تابع یک logger با نام ماژول برمی‌گرداند.

**کارکرد:**
- برای هر فایل/ماژول، logger اختصاصی می‌سازد
- باعث می‌شود لاگ‌ها بر اساس نام ماژول مرتب و قابل پیگیری باشند

**نمونه استفاده:**
```python
from utils.logger import get_logger

logger = get_logger(__name__)
