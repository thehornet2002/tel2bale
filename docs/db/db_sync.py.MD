# docs /db/db_sync.py

این فایل مسئول ساخت اتصال sync به دیتابیس SQLite و مدیریت خودکار تراکنش‌هاست.
تمام کدهای sync پروژه (مثل `model_sync.py`) برای دسترسی به دیتابیس از این فایل استفاده می‌کنند.

## ثابت‌ها

### `DB_NAME = "bot.db"`
نام فایل دیتابیس SQLite که در ریشه پروژه ساخته می‌شود.

## توابع

### `create_connection() -> sqlite3.Connection`
یک اتصال جدید به دیتابیس می‌سازد.

- اتصال به `bot.db` را باز می‌کند.
- `row_factory` را روی `sqlite3.Row` تنظیم می‌کند تا ردیف‌ها مثل dict قابل دسترسی باشند.
- `PRAGMA journal_mode=WAL` را فعال می‌کند (برای هم‌زمانی بهتر خواندن/نوشتن).
- `PRAGMA foreign_keys=ON` را فعال می‌کند.
- در صورت بروز خطا، آن را لاگ کرده و دوباره raise می‌کند.

### `get_db()` (context manager)
یک context manager برای مدیریت خودکار اتصال و تراکنش.

**رفتار:**
- با `create_connection()` یک اتصال می‌سازد.
- اتصال را `yield` می‌کند تا داخل بلوک `with` استفاده شود.
- اگر بدون خطا تمام شود: `commit()` اجرا می‌شود.
- اگر خطایی رخ دهد:
  - `rollback()` اجرا می‌شود.
  - خطا لاگ شده و دوباره raise می‌شود.
- در نهایت (finally) اتصال با `close()` بسته می‌شود، صرف‌نظر از موفقیت یا شکست.

**استفاده:**
```python
with get_db() as db:
    db.execute(...)
```
