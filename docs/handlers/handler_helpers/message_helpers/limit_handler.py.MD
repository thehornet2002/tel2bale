# docs /handlers/handler_helpers/message_helpers/limit_handler.py

این فایل هندلرهای تنظیم سقف دانلود (چه برای همه کاربران، چه برای یک کاربر خاص) را پیاده‌سازی می‌کند. تمام توابع فقط برای ادمین در دسترس‌اند (`admin_only`).

## توابع

### `async set_limit_all_send_volume(message, user_id)`
دریافت و اعمال مقدار سقف دانلود برای همه کاربران.

- متن پیام به `float` تبدیل می‌شود؛ در صورت شکست تبدیل (`ValueError`)، پیام خطا «لطفا فقط عدد ارسال کنید» ارسال می‌شود.
- در صورت موفقیت:
  - سقف همه کاربران با `model_async.set_limit_download_all(value)` تغییر می‌کند.
  - سقف پیش‌فرض کاربران جدید با `model_async.set_limit_volume(value)` به‌روزرسانی می‌شود.
  - state ادمین به `'management'` بازمی‌گردد و پیام موفقیت نمایش داده می‌شود.

### `async set_limit_send_id(message, user_id)`
دریافت شناسه کاربر هدف برای تنظیم سقف دانلود اختصاصی.

- با `get_valid_id` شناسه عددی از پیام استخراج می‌شود؛ در صورت نامعتبر بودن، تابع خارج می‌شود.
- state ادمین به `f'set_limit_{target_id}'` تغییر می‌کند (شناسه کاربر هدف داخل خود state ذخیره می‌شود).
- از ادمین خواسته می‌شود مقدار محدودیت (به GB) را وارد کند.

### `async set_limit_set_limit(message, user_id)`
دریافت مقدار عددی سقف و اعمال آن برای کاربر هدفی که در state ذخیره شده بود.

- متن پیام به `float` تبدیل می‌شود؛ در صورت شکست، پیام خطا نمایش داده می‌شود.
- state فعلی ادمین با الگوی `^set_limit_(\d+)$` بررسی می‌شود تا شناسه کاربر هدف استخراج شود.
- اگر منطبق بود: سقف کاربر هدف با `model_async.set_limit_download(target_id, limit_value)` تنظیم می‌شود، state ادمین به `'management'` بازمی‌گردد و پیام موفقیت نمایش داده می‌شود.
- در صورت هر خطای دیگری: state به `'management'` بازمی‌گردد و پیام خطا نمایش داده می‌شود.
