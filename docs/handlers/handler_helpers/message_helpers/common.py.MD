# docs /handlers/handler_helpers/message_helpers/common.py

توابع و دکوریتورهای مشترک بین چند فایل هندلر پیام، برای جلوگیری از تکرار کد.

## توابع

### `admin_only(func)`
دکوریتوری مشابه `admin_required` (در `callback_helpers/decorators.py`) اما برای هندلرهای پیام.

**رفتار:**
- با `model_async.check_admin(user_id)` بررسی می‌کند کاربر ادمین است یا نه.
- اگر ادمین نباشد: بدون اجرای تابع اصلی و بی‌سروصدا خارج می‌شود.
- اگر ادمین باشد: تابع اصلی با همان آرگومان‌ها اجرا می‌شود.

### `async get_valid_id(message: Message) -> int | None`
بررسی می‌کند متن پیام یک شناسه عددی معتبر است یا نه.

- اگر `message.text` خالی باشد یا فقط شامل رقم نباشد (`isdigit()` نادرست): پیام «لطفا فقط شناسه عددی ارسال کنید» به کاربر ارسال شده و `None` برگردانده می‌شود.
- در غیر این صورت مقدار عددی متن به‌صورت `int` برگردانده می‌شود.

این تابع در چندین هندلر (بن/آنبن، افزودن ادمین، تنظیم شناسه بله و ...) برای اعتبارسنجی ورودی‌های عددی استفاده می‌شود.
