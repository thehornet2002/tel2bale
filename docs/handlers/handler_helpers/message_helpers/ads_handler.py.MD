# docs /handlers/handler_helpers/message_helpers/ads_handler.py

این فایل هندلرها و توابع کمکی مربوط به مدیریت کانال‌های جوین اجباری (ads channel) را پیاده‌سازی می‌کند: نرمال‌سازی ورودی کاربر، اعتبارسنجی واقعی کانال از طریق تلگرام، افزودن و حذف کانال.

## توابع کمکی

### `normalize_telegram_channel_input(raw_value: str) -> str | int | None`
ورودی خام کاربر (که می‌تواند فرم‌های مختلفی داشته باشد) را به یک فرمت استاندارد (`@username` یا `chat_id` عددی) تبدیل می‌کند.

**فرمت‌های قابل قبول:**
- `@channel` یا `channel`
- `https://t.me/channel` یا `telegram.me/channel`
- شناسه عددی چت مثل `-1001234567890`

**رفتار:**
- ورودی خالی → `None`
- فقط اولین کلمه از ورودی در نظر گرفته می‌شود.
- اگر لینک باشد: باید هاست آن `t.me` یا `telegram.me` باشد؛ لینک‌های دعوت خصوصی (`+` یا `joinchat/`) رد می‌شوند (`None`).
- پیشوند `@` حذف می‌شود.
- اگر مقدار باقی‌مانده کاملاً عددی باشد (با احتمال علامت منفی)، به `int` تبدیل می‌شود.
- در غیر این صورت باید با الگوی نام کاربری تلگرام (`[A-Za-z0-9_]{5,32}`) مطابقت داشته باشد؛ در غیر این صورت `None`.
- خروجی نهایی رشته‌ای به شکل `@username` یا عدد `chat_id` است.

### `ads_channel_aliases(raw_value, normalized_value=None) -> set[str]`
مجموعه‌ای از تمام حالت‌های ممکن یک کانال (خام، بدون `@`، نرمال‌شده) را می‌سازد تا هنگام حذف کانال، بتوان با هر فرمتی که در کانفیگ ذخیره شده مطابقت داد.

### `async resolve_and_validate_ads_channel(message, raw_value) -> tuple[str | None, str | None]`
ورودی کاربر را نرمال‌سازی و از طریق API تلگرام صحت واقعی آن را بررسی می‌کند. خروجی به‌صورت `(channel_value, error_message)` است؛ فقط یکی از این دو مقدار غیر `None` است.

**مراحل:**
1. نرمال‌سازی با `normalize_telegram_channel_input`؛ در صورت نامعتبر بودن فرمت، پیام راهنما برگردانده می‌شود.
2. تلاش برای گرفتن اطلاعات چت با `message._client.get_chat(normalized)`.
   - `UsernameInvalid` / `UsernameNotOccupied` / `PeerIdInvalid` / `ChannelInvalid` → «کانالی با این مشخصات پیدا نشد.»
   - `ChannelPrivate` → پیام راهنما برای عضو کردن ابتدا ربات در کانال
   - سایر خطاها → پیام خطای عمومی همراه با متن استثنا
3. عضویت خود ربات در کانال با `get_chat_member(chat_id, "me")` بررسی می‌شود؛ در صورت خطا یا نبود عضویت معتبر (`creator`, `administrator`, `member`, `owner`)، پیام خطای مربوطه برگردانده می‌شود.
4. اگر کانال `username` عمومی داشته باشد، `@username` برگردانده می‌شود؛ در غیر این صورت `chat_id` به‌صورت رشته برگردانده می‌شود (برای کانال‌های خصوصی که ربات در آن‌ها عضو است).

## هندلرها

### `async enter_join_ads_channel(message, user_id)`
دریافت و افزودن یک کانال جدید به لیست جوین اجباری. فقط برای ادمین (`admin_only`).

- کانال با `resolve_and_validate_ads_channel` بررسی و نرمال‌سازی می‌شود؛ در صورت خطا، پیام مربوطه نمایش داده می‌شود.
- کانال معتبر با `add_ads_channel(channel_value)` (تابعی از `config.py`) به فایل `.env` اضافه می‌شود؛ اگر قبلاً وجود داشته باشد، پیام مربوطه نمایش داده می‌شود.
- در صورت موفقیت: state ادمین به `'management'` بازمی‌گردد و پیام تأیید همراه با شناسه ذخیره‌شده نمایش داده می‌شود.

### `async enter_delete_join_ads(message, user_id)`
دریافت و حذف یک کانال از لیست جوین اجباری. فقط برای ادمین (`admin_only`).

- کانال ابتدا با `resolve_and_validate_ads_channel` بررسی می‌شود (خطای احتمالی این مرحله نادیده گرفته می‌شود، چون هدف فقط گرفتن مقدار نرمال‌شده است).
- برای هر یک از حالت‌های ممکن کانال (`ads_channel_aliases`)، حذف با `remove_ads_channel(alias)` امتحان می‌شود تا یکی موفق شود.
- اگر هیچ‌کدام موفق نشد: پیام «این کانال در لیست Join اجباری پیدا نشد» نمایش داده می‌شود.
- در صورت موفقیت: state ادمین به `'management'` بازمی‌گردد و پیام تأیید حذف نمایش داده می‌شود.
