# docs /handlers/handler_helpers/message_helpers/messaging_handler.py

این فایل هندلرهای ارسال پیام همگانی (broadcast) و ارسال پیام مستقیم به یک کاربر خاص را پیاده‌سازی می‌کند. تمام توابع فقط برای ادمین در دسترس‌اند (`admin_only`).

## توابع

### `async enter_ads_message(message, user_id)`
دریافت پیام همگانی از ادمین و ارسال آن به تمام کاربران (به‌جز ادمین‌ها).

**رفتار:**
- لیست همه `telegram_id`ها با `model_async.get_all_telegram_ids()` گرفته می‌شود.
- برای هر کاربر:
  - اگر خودش ادمین باشد، رد می‌شود (`continue`).
  - پیام با `message.copy(chat_id=tg_id)` برای او کپی/فوروارد می‌شود.
  - بین ارسال هر پیام `0.05` ثانیه تأخیر داده می‌شود (`asyncio.sleep`) تا از rate limit تلگرام جلوگیری شود.
  - در صورت شکست ارسال برای یک کاربر، شمارنده `failed` افزایش می‌یابد و ادامه می‌دهد.
- در پایان، گزارش تعداد ارسال موفق/ناموفق به ادمین نمایش داده شده و state او به `'home'` بازمی‌گردد.

### `async send_message_chat_id(message, user_id)`
دریافت شناسه کاربر هدف برای ارسال پیام مستقیم.

- با `get_valid_id` شناسه عددی از پیام استخراج می‌شود؛ در صورت نامعتبر بودن، تابع خارج می‌شود.
- state ادمین به `f'send_message_{target_id}'` تغییر می‌کند.
- از ادمین خواسته می‌شود پیام موردنظر را ارسال کند.

### `async send_message_send_message(message, user_id)`
دریافت متن/محتوای پیام و ارسال آن به کاربر هدفی که در state ذخیره شده بود.

- state فعلی ادمین با الگوی `^send_message_(\d+)$` بررسی می‌شود تا شناسه کاربر هدف استخراج شود.
- اگر منطبق بود: پیام با `message.copy(chat_id=target_id)` برای کاربر هدف ارسال می‌شود، پیام موفقیت به ادمین نمایش داده شده و state او به `'home'` بازمی‌گردد.
- در صورت هر خطایی (مثلاً کاربر ربات را بلاک کرده): پیام خطا نمایش داده شده و state به `'home'` بازمی‌گردد.
