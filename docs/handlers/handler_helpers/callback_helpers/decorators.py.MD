# docs /handlers/handler_helpers/callback_helpers/decorators.py

این فایل یک دکوریتور کمکی برای محدود کردن هندلرهای callback به کاربران ادمین فراهم می‌کند.

## توابع

### `admin_required(func)`
دکوریتوری که یک تابع هندلر با امضای `(message, user_id, ...)` را می‌گیرد و آن را فقط برای ادمین‌ها قابل اجرا می‌کند.

**رفتار:**
- با `check_admin(user_id)` بررسی می‌کند کاربر ادمین است یا نه.
- اگر ادمین نباشد: تابع بدون اجرا و بی‌سروصدا خارج می‌شود (`return` بدون مقدار).
- اگر ادمین باشد: تابع اصلی (`func`) با همان آرگومان‌ها اجرا و نتیجه آن برگردانده می‌شود.
- از `functools.wraps` استفاده می‌کند تا نام و متادیتای تابع اصلی حفظ شود.

این دکوریتور روی هندلرهای مدیریتی در `callback_helpers/admin/*` استفاده می‌شود تا کاربران عادی نتوانند به عملیات ادمین دسترسی پیدا کنند.
