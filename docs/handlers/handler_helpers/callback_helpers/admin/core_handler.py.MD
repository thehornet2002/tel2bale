# docs /handlers/handler_helpers/callback_helpers/admin/core_handler.py

این فایل هندلرهای اصلی پنل مدیریت (ورود به پنل، گرفتن بک‌آپ دیتابیس، نمایش کاربران پرمصرف، پیام‌های پشتیبانی و تغییر لینک دونیت) را پیاده‌سازی می‌کند. تمام توابع با `admin_required` محافظت شده‌اند.

## توابع

### `async management(message, user_id) -> None`
ورود به پنل مدیریت.

- state روی `"management"` تنظیم می‌شود.
- پیام خوش‌آمدگویی همراه با کیبورد پنل مدیریت (`build_management_keyboard`) نمایش داده می‌شود.

### `back_to_management = management`
از آنجا که صفحه «management» و «بازگشت به مدیریت» دقیقاً یک محتوا و رفتار یکسان دارند، به‌جای تکرار کد، یک alias مستقیم برای تابع `management` تعریف شده است.

### `async get_db(message, user_id) -> None`
گرفتن و ارسال نسخه پشتیبان دیتابیس به ادمین.

- با `create_database_backup_async()` (از `db/backup.py`) یک فایل backup موقت ساخته می‌شود.
- فایل با `message.reply_document` برای ادمین ارسال می‌شود.
- در صورت خطا، پیام خطا با متن استثنا و کیبورد بازگشت نمایش داده می‌شود.
- در بخش `finally`، فایل backup موقت از دیسک حذف می‌شود (چه موفق چه ناموفق) تا فضای اضافی روی سرور باقی نماند.

### `async show_10_high(message, user_id) -> None`
نمایش ۱۰ کاربر با بیشترین حجم دانلود.

- با `get_top_users()` لیست کاربران گرفته می‌شود.
- برای هر کاربر یک خط با فرمت `Telegram ID | Bale ID | Downloaded Volume` ساخته می‌شود (اگر `bale_id` نداشته باشد، `-` نمایش داده می‌شود).
- نتیجه با کیبورد بازگشت به پنل مدیریت نمایش داده می‌شود.

### `async show_support_messages(message, user_id) -> None`
نمایش پیام‌های پشتیبانی خوانده‌نشده کاربران.

- با `get_unread_support_message()` یک پیام پشتیبانی خوانده‌نشده گرفته می‌شود.
- اگر پیامی نباشد: متن «پیامی وجود ندارد» با کیبورد بازگشت نمایش داده می‌شود.
- در غیر این صورت: شناسه فرستنده و متن پیام همراه با `support_keyboard()` (برای پاسخ یا رد کردن) نمایش داده می‌شود.

### `async change_donation_link(message, user_id) -> None`
شروع فرآیند تغییر لینک حمایت مالی (دونیت).

- state روی `'change_donation_link'` تنظیم می‌شود.
- از ادمین خواسته می‌شود لینک جدید دونیت را وارد کند.
