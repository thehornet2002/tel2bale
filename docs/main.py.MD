# docs main.py

این فایل شامل توابع اصلی برای شروع ربات و تنظیم اولیه‌ی دستورات است.

## توابع

### main
- **کارکرد:** شروع اجرای برنامه از این تابع.
- **خلاصه:** این تابع نقطه شروع ربات است و برنامه را برای کارکرد آماده می‌کند.

### setup_bot_commands
- **کارکرد:** تنظیم اولیه دستورات ربات.
- **خلاصه:** این بخش فقط لیست/تنظیمات دستورات را برای نمایش و استفاده‌ی کاربر آماده می‌کند.  
  **نکته:** handler اجرای دستورات در اینجا رخ نمی‌دهد و فقط تنظیمات انجام می‌شود.
