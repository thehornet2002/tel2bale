# docs /requirements.txt

این فایل وابستگی‌های پروژه (Python packages) را مشخص می‌کند. هر چیزی که پروژه برای اجرا، اتصال‌ها و ارتباط با سرویس‌های خارجی نیاز دارد، داخل این لیست آمده است.

## پکیج‌ها

- **kurigram**
  - کارکرد: ارتباط ربات با سرورهای تلگرام از طریق **mtproto**.
  - نتیجه: امکان اجرای منطق تلگرام (مثل دریافت/ارسال پیام‌ها) با پروتکل mtproto فراهم می‌شود.

- **TgCrypto**
  - کارکرد: کتابخانه/وابستگی موردنیاز برای کار کردن **kurigram**.
  - نتیجه: بخش‌های رمزنگاری/توابع موردنیاز mtproto به کمک این پکیج تامین می‌شوند.

- **aiosqlite**
  - کارکرد: ارتباط با **SQLite** در حالت **async**.
  - نتیجه: عملیات دیتابیس بدون بلاک‌کردن event loop انجام می‌شوند (برای پروژه‌های async مناسب‌تر است).

- **python-dotenv**
  - کارکرد: خواندن فایل **.env** و تزریق مقادیر آن به محیط اجرای برنامه.
  - نتیجه: تنظیمات حساس/متغیرها (مثل توکن‌ها، کلیدها، آدرس‌ها و …) می‌توانند خارج از کد مدیریت شوند.

- **aiohttp**
  - کارکرد: ارسال درخواست‌های شبکه (**HTTP requests**) به شکل **async**.
  - نتیجه: سمت **bale** امکان تعامل وب/APIها را به صورت غیرهمزمان و کارآمد دارد.

- **aioboto3**
  - کارکرد: رابط **async** برای سرویس‌های AWS (به‌خصوص **S3**).
  - نتیجه: پروژه می‌تواند فایل‌ها را در S3 ارسال/دریافت کند و عملیات مدیریت سرور را به شکل async انجام دهد.

- **pysqlite**
  - کارکرد: ارتباط با **SQLite** در حالت **sync**.
  - نتیجه: اگر بخشی از پروژه نیاز به عملیات synchronous دیتابیس داشته باشد، از این پکیج استفاده می‌شود.
